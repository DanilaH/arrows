# Arrows / Стрелки

Минималистичная головоломка для Android / RuStore по согласованному видео-референсу.

**Состояние: 0.8.1.** Кампания из 120 фиксированных полей, отдельные сохранения кампании и дат, 365 задач 2026 года, локальные достижения и месячные кубки. Первые двадцать полей переработаны для новых попыток; первые четыре дополнительно поджаты по видео-референсу: маленькие плотные рисунки с соседними линиями. Все сохранённые попытки и старые награды сохраняют свою геометрию/оформление при обновлении. Светлая/тёмная темы, RU/EN, независимые звук/вибрация, рекламные переходы и долговечная выдача наград подключены.

Главный экран получил новые карточки и две сгенерированные иллюстрации; кнопки, меню и окна — короткие переходы с поддержкой уменьшенного движения. Добавлены собственные иконка и экран запуска. Контрольные поля доступны только в изолированных тестовых сценариях и отсутствуют в обычном APK. [Текущий статус и открытые проверки](docs/HANDOFF.md), [банк кампании](docs/STAGE_E_CAMPAIGN_BANK.md), [оформление приложения](docs/STAGE_E_IDENTITY.md), [новый интерфейс и начальные поля](docs/STAGE_F_UX_POLISH.md).

Это debug-сборка с тестовой рекламой. Проверка реальных показов/награды и кабинета аналитики, телефонная приёмка, окончательная подпись и материалы RuStore остаются обязательными. League и коммерческие/аккаунтные сценарии остаются явно открытыми, без фиктивного UI.

## Запуск

Node 24 (см. `.nvmrc`), npm:

```sh
npm ci
npm run dev
```

```sh
npm run check                 # strict TypeScript, unit tests, production build
npx playwright install chromium
npm run test:browser          # browser smoke against dist; build first
npm run android:sync          # build + sync web assets/native plugins
npm run android:open          # Android Studio
```

Для Android: JDK 21, Android SDK platform 36 / build-tools 36.0.0. Из `native/android` выполнить `./gradlew assembleDebug` после `npm run android:sync`. В CI отдельный Android job собирает debug APK кампании и ежедневных задач; контрольный каталог в него не входит. Это не стор-релиз. APK использует `com.danilah.arrows`. Секреты и release keystore не входят в репозиторий.

## Основа

TypeScript 7.0.2, Vite 8.2.2, Phaser 4.2.1, Capacitor 8.6.0. `mini-games-kit` закреплён на [`a932526`](https://github.com/DanilaH/mini-games-kit/tree/a9325265e87583a4872cf6a158e1e881a0d7508e). Установку воспроизводит `package-lock.json`; зависимость не отслеживает `main`.

## Границы кода

`src/app` — запуск, viewport, локализация и browser/native lifecycle. `src/game` — представление Phaser. `native/android` — нативная оболочка. `tests/unit` — локальные контракты интеграции, `tests/browser` — настоящий браузер и production bundle.

`src/domain` — правила и геометрия, `src/content` — фиксированные поля кампании/daily и каталоги наград; контрольные поля импортируются только тестовым входом, `src/input` — жесты и CSS/world-камера, `src/game` — Phaser-представление и DOM-управление. Генерация контрольных силуэтов выполняется отдельно командой `npm run content:controls`. Кампания и долговечная попытка управляются `src/progression/save.ts`; представление не владеет сохранением победы.

Исходники оформления находятся в `tools/brand/art.mjs`; `npm run brand:generate` обновляет SVG/native vector-ресурсы, а обычная сборка проверяет их согласованность. Исторические GIF-скрипты контрольных полей запускаются на записанных в их отчётах ревизиях; текущая запись запуска — `tools/capture-identity-gif.mjs`.
