# Первый запуск: выбор темы —0.37.0/code52

Поверх2ed1023 сохранены новый launcher/store icon, production signing pin/workflow и весь архив0.35. Владелец попросил выбирать тему при первом запуске с плавной сменой цвета всего меню.

На настоящем Home под живой эмблемой показаны две компактные кнопки «Светлая / Тёмная», подсказка о возможности изменить выбор и существующая «Играть». Без нового диалога/отдельного подтверждения. Весь интерфейс предпросмотра получает общие интерполируемые цветовые токены; фон, текст, эмблема, навигация и кнопки меняются за400ms. Быстрая смена направления использует отображённое браузером промежуточное состояние. Registered inherited CSS colors также достаются outgoing snapshots; нет перекрывающего crossfade/перехвата ввода или отдельного RAF.

Предпросмотр имеет один ограниченный440ms cleanup timeout, который обновляется на следующий выбор и уничтожается с владельцем. Он не владеет результатом/сохранением/готовностью ввода. Reduced motion переключает сразу, включая изменение этой настройки во время перехода. Если WebView не поддерживает typed CSS colors, выбор остаётся функциональным с мгновенным цветом.

SettingsStore.firstVisit=true только после подтверждённого отсутствия preferences. Некорректное/недоступное/запоздалое чтение не вызывает внезапного welcome. Существующие preferences сохраняют свой выбор. У сыгранного профиля без settings welcome также не появляется; отдельный pilot/review контекст исключён. Флаг памяти не расширяет persisted GameSettings/schema: наличие записанных preferences само закрывает первое знакомство.

Выбор темы сохраняет существующий документ settings через прежнюю очередь. «Играть» записывает выбранный или нетронутый светлый default и сразу входит в игру; результат/жизни/подсказки/архив/SDK не ждут ни preference write, ни цвет. При ошибке preferences игра продолжает работать с выбором в текущей сессии и прежней отдельной Settings recovery. Если запись не удалась, уже сыгранный профиль предотвращает повторный welcome.

Не менялись GameSave/decoder/archive format, content/generators/attempts, права/receipts/ошибки/flawless/lifetime gift, рекламные правила, звуки, signing identities, production secrets и kit pin. Welcome не добавляет новое событие/эксперимент, рекламу или валюту. Дальнейшая смена темы остаётся в настройках. При обновлении существующей установки first-visit экран намеренно не навязывается.
