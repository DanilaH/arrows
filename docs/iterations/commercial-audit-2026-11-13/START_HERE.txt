ВОСПРОИЗВЕДЕНИЕ
Скрипты в probes проверяют точный HEAD. Запускайте на изолированном checkout указанного SHA с установленными зависимостями; не делайте reset актуальной рабочей ветки.
Требуются Node 24+ и npm ci в checkout. Для UI также npm run build и установленный Playwright Chromium.
Задайте ARROWS_REPO равным абсолютному пути этого изолированного checkout.

node probes/ads-readiness-probe.mjs "$ARROWS_REPO"
node probes/help_probe.mjs "$ARROWS_REPO"
node probes/measurement/reproduce-offer-choices.mjs "$ARROWS_REPO"
node probes/measurement/reproduce-transport-loss.mjs "$ARROWS_REPO"

UI-скрипт сам поднимает временный preview на 4197 и закрывает его. Результаты записываются рядом со скриптами; исходные результаты аудита также сохранены в evidence.
Команды не запускают реальные рекламные показы и не отправляют события в пользовательскую аналитику.
