Подтверждаю: предложенный один milestone первого самостоятельного успешного хода после полного использования A1/A2/A3 — **новая ограниченная рекомендация этого аудита**, не дефект выполнения старого ТЗ.

Формулировка правильно исключает исполнение самой помощи, ещё активный маршрут, бонусные и естественные автоматические удаления; победа, которой завершилась помощь, отдельно не считается провалом из-за отсутствия следующего хода. Численные эффекты на удержание/доход не обещаются.

Деталь для будущей реализации, не обязательная правка текущего отчёта: «самостоятельный» следует определить как обычный принятый ручной ход. Если игрок сразу получает следующую подсказку, её исполнение тоже не должно удовлетворять milestone предыдущей помощи. Смена попытки и финал должны завершать/ограничивать наблюдение по явно выбранному правилу. Для предложенного active elapsed нужна зафиксированная исходная отметка момента полного использования, а не время рекламного показа.
