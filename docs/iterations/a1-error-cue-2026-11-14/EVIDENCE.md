## 3. Измерение

Существующий export покрывает завершение/выход/рестарт, рекламу и M1 после использованной помощи. Он не фиксирует готовность A1 в момент первой ошибки и реальный показ нового cue. Поэтому V1 добавляет только локальные opportunity/shown.

`assistance_assignment` уже относится к типу помощи. Его нельзя использовать как назначение cue/control. Произвольные поля в текущем `level_error` также нельзя добавлять: контракт проверяет точные ключи/типы. Внешний локальный trace позволяет подготовить QA без изменения AppMetrica и native schema.

Первый обычный успешный ход среди всех подходящих игроков не покрывается M1. Этот дополнительный observer отложен; текущий пакет не обещает такую метрику.
