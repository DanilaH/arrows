# Приёмка нового QA-кандидата

Исходный статус всех проверок нового cue: **NOT RUN**. В EVIDENCE.md и baseline_probe/ находятся только наблюдения неизменённой версии 0.25.0; они не являются приёмкой ещё не реализованного кандидата.

| ID | Сценарий | Ожидаемый результат |
| --- | --- | --- |
| Q01 | off, обычная игра | Нет cue и его trace; текущий UI/права сохраняются. |
| Q02 | control, первая подходящая ошибка | Одна opportunity, нет shown и декоративного акцента. |
| Q03 | cue, первая ошибка, A1/ready, Hint давно видна | Одна opportunity и один фактический shown после error feedback; акцент конечен. |
| Q04 | Повтор прежней ошибочной стрелки | Нет нового cue/opportunity; сохраняется прежняя стоимость ошибки. |
| Q05 | Ошибка по второй новой стрелке | Даже при result.first=true и другом hearts нет второй opportunity. |
| Q06 | Первая ошибка до трёх активных секунд | Cue отсутствует; последующее появление Hint штатное, без отложенного акцента. |
| Q07 | Ошибка на границе появления Hint | Обычный hintReady и cue не наслаиваются; условия нельзя получить только post-sync проверкой hidden=false. |
| Q08 | Hint видна, readiness idle/loading/backoff/unavailable/disabled | Нет cue; обычная кнопка и её объяснение доступны по прежним правилам. |
| Q09 | Ready истёк до показа / изменился во время cue | Opportunity не удаляется, shown только если был реальный кадр; cue отменяется, готовность не подделывается. |
| Q10 | Активная/резервная/legacy помощь; A2/A3/A4/fallback; B1 | Cue не появляется; earned-права, бесплатный claim и старые варианты не меняются. |
| Q11 | Быстрый правильный ход между ошибкой и показом | Старый акцент не догоняет уже решённое затруднение. |
| Q12 | Hint нажата до/во время cue | Действие срабатывает один раз, cue исчезает; повторного SDK request и выдачи нет. |
| Q13 | Другая помощь или поздняя награда | Кандидат уступает текущему праву и presentation; не пересчитывает план. |
| Q14 | Back/меню/модалка/рестарт/фон/resize/смена языка/destroy | Только свой cue и pending-start очищены; возврат не повторяет старый сигнал. |
| Q15 | Удержание центра и 2-3 px внутри края Hint | Геометрия hit area до/во время/после одинакова; release/cancel/keyboard и исходный transform сохранены. |
| Q16 | Normal/reduced motion, две темы, узкий экран | Текст/readiness/video-mark не скрываются, нет overflow/сдвига; эффект завершается и уходит в idle. |
| Q17 | Уже идёт unlock/award/обычное появление Hint | Cue пропущен; его helper не отменяет чужой arrival и не скрывает anchor. |
| Q18 | Reload старого save после первой ошибки/с earned/help reserve | Нового move-повода нет; попытка, ошибки, права и камера восстановлены без повторного cue. |
| Q19 | Попытка без ошибок → смена будущего QA-выбора в Settings → reload → первая ошибка | Текущая попытка сохраняет прежний режим через reload; только новая попытка получает выбранный режим. Cue mode не меняет HelpVariant/assistance-v1. |
| Q20 | Доставка .playtest | Прежний package/certificate, увеличенный code, тестовая реклама, analytics OFF, настоящий APK-пакет и честно маркированные записи. |

Проверки должны наблюдать реальные последствия: состояние writer/offer, DOM hit area, отсутствие лишнего SDK-запроса, число фактических показов и очистку владельца. Тест, который только повторяет ту же eligibility-функцию, не доказывает корректную интеграцию.

Общий успешный CI не означает проверку удовольствия, телефонной вибрации, native SDK, кабинета или денег. Эти статусы сохраняются отдельно.
