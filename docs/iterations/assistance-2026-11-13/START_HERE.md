# Стрелки: пакет ТЗ для агента

Версия пакета: 1.0. Дата: 13 ноября 2026, Екатеринбург.

## Что нужно сделать

Довести помощь в «Стрелках» до понятного, ощутимого результата: улучшить выбор обычной подсказки, добавить ограниченный автокаскад, затем ручной маршрут до цели. Связать действия плавными переходами цвета, формы, звука и вибрации. Подготовить измерение денег и отдельный прототип режима освобождения цели.

Это инструкция для реализации в **DanilaH/arrows**. Сам пакет не является готовой реализацией, APK или доказательством роста дохода.

## Порядок чтения

1. Текущие `AGENTS.md`, `docs/HANDOFF.md`, `docs/PROJECT_DECISIONS.md`, `docs/KIT_REUSE.md` в рабочем репозитории.
2. `TASK.md` - границы, этапы, игровые правила и сохранения.
3. `FEEL.md` - внешний вид и ощущения каждого перехода, звук, вибрация и производительность.
4. `MEASUREMENT.md` - реклама, заработанные права, события и деньги.
5. `ACCEPTANCE.md` - проверяемые сценарии и требования к поставке.
6. `SOURCES.md` - факты, источники, ограничения доказательств и воспроизведение примеров.

`ARROWS_BRIEF.pdf` - краткая карта пакета для владельца. При расхождении с подробными файлами PDF не переопределяет требования. `AGENT_PROMPT.txt` - готовый стартовый промпт.

Сначала закончи и выдай поставку 1. Затем продолжай поставки 2-4 отдельными изменениями. Не обрывай работу на плане или красивом демо. Не включай несколько продуктовых экспериментов одновременно для одного игрока/попытки. Отсутствие доступа к денежному кабинету не блокирует подготовку тестовой APK: отдельно укажи `ENGINEERING VERIFIED` и `REVENUE NOT VERIFIED`.

## Что сохраняем

- Android/RuStore и существующий browser dev surface. Без внедрения Yandex Games web SDK.
- Ортогональную геометрию, hit testing, frozen campaign/daily/trophy identities и все старые встроенные попытки.
- Три жизни; первое ошибочное нажатие на отдельную стрелку стоит жизнь, повторное на неё - нет.
- Автоснятие ранее ошибочно отмеченных стрелок в законном порядке; история ошибок остаётся.
- Один бесплатный continue на весь сохранённый профиль, затем действующее rewarded-продолжение.
- Безошибочное прохождение означает отсутствие ошибок. Подсказка сама по себе не отменяет медаль.
- Три активные секунды до предложения Hint. Это не срок действия заработанной подсказки.
- Текущий рекламный ритм, стартовую защиту, отсутствие баннера и показ interstitial только в предусмотренном переходе.
- Пины, мягкие границы поля, непрерывность Home/поле, управление камерой, idle rendering, Canvas fallback, принятый характер обычного звука.

Описанные A2/A3/A4/B1 - явные новые продуктовые изменения. Они локально дополняют исторические ограничения прежних релизов; не дают права менять остальные правила или переписывать старые награды.

## Что считать готовой поставкой

- Изменения реализованы в актуальной рабочей ветке, пройдены обязательные проверки проекта и релевантные сценарии `ACCEPTANCE.md`.
- Выдана реальная APK с package/version/certificate/SHA-256; `.playtest` обновляется по совместимому пути, не требует удаления реального прогресса.
- В `.playtest` принудительно тестовая реклама и отключённая продуктовая аналитика; прогресс отделён от основной игры.
- Есть короткие записи **реальной сборки**: обычная подсказка, каскад, прерывание перехода, плотное поле. Для звука есть видео с реальным аудиовыходом; GIF звука не доказывает.
- Браузерная запись, управляемый SDK, эмулятор и физический Android подписаны различными источниками. Не выдавать один тип доказательств за другой.
- Перечислены пройденные проверки, реальные ограничения, следующая изолированная задача и `KIT IMPACT`.

## Работа с mini-games-kit

По `TASK_ROUTER.md` выбирай 1-2 релевантных направления на этап. Для C - rewarded/lifecycle/storage и measurement; для F - feel/performance/accessibility; для B1 - puzzle design/content validation. Не перечитывай весь архив перед каждым изменением.

До общего механизма проверь `docs/API.md` именно на установленном runtime pin. Используй существующие activity, durable receipt, audio и finite motion контракты. Прочитай текущий `KIT_TRANSFER_AUDIT_2026-11-13.md`, чтобы не дублировать уже выявленные общие проблемы.

После реализации: `NONE / REUSE / IMPROVE / CANDIDATE / EXTRACTED`, конкретный API/дефект, воспроизведение и статус upstream. Этот игровой пакет не пушить в mini-games-kit. Автоматический перенос игрового кода, общий рефакторинг кита, публикация в магазине и изменение других игр в задачу не входят.
